# CorridaCerta AI — protótipo Android

Aplicativo experimental de análise local de ofertas da Uber e Lalamove, sem aceite ou recusa automática. O serviço de acessibilidade precisa ser ativado manualmente. A análise depende de os aplicativos exporem os textos para acessibilidade; os nomes de pacotes podem variar. Os cálculos não incluem pedágios, retorno vazio ou todos os custos reais, e a soma de distâncias/tempos da tela pode superestimar trajetos. **Não está validado em dispositivo real e não há garantia de resposta em 4 segundos.**

## APK pelo GitHub
Envie a estrutura de pastas inteira para a raiz do repositório (não o ZIP como arquivo único), depois abra **Ações > Compilar APK > Executar fluxo de trabalho**. Se a compilação terminar com sucesso, baixe o artefato `CorridaCertaAI-debug-apk`.

## Segurança
Não usa internet nem envia dados de ofertas. Não aceita corridas automaticamente. Teste parado, nunca manipulando o celular enquanto dirige. Confira os termos das plataformas e permissões de acessibilidade antes de utilizar.
